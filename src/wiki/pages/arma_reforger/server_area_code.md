Official servers sport a letters code that is an area code. Here is a list of them with their meaning:

| Code | Description |  |
| --- | --- | --- |
| Code | **Area** | **City** |
| EU-FFM | Europe | Frankfurt am Main |
| US-LA | United States | Los Angeles |
| US-MI | United States | Miami |
| US-NY | United States | New York |
| US-SF | United States | San Francisco |
| US-WA | United States | Washington DC |
| AP-SG | Asia-Pacific | Singapore |
| AP-TO | Asia-Pacific | Tokyo |
| AP-SY | Asia-Pacific | Sydney |
