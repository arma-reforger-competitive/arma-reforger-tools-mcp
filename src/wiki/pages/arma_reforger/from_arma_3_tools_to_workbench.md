This page offers an equivalence table between Arma 3 Tools and Workbench, the new Enfusion Tools suite.

Equivalences are not always possible nor entirely accurate, as some functionalities do not have a perfect match, if any.

| Arma 3 Tool | Function | Workbench equivalent |
| --- | --- | --- |
| [Addon Builder](https://community.bistudio.com/wiki/Addon_Builder) | Addon packing | [Arma Reforger:Resource Manager](https://community.bistudio.com/wiki/Arma_Reforger:Resource_Manager): Pack Project |
| [Binarize](https://community.bistudio.com/wiki/Binarize) | Addon binarisation | [Arma Reforger:Resource Manager](https://community.bistudio.com/wiki/Arma_Reforger:Resource_Manager): Import (model) |
| [BinMake](https://community.bistudio.com/wiki/BinMake) | Addon binarisation | [Arma Reforger:Resource Manager](https://community.bistudio.com/wiki/Arma_Reforger:Resource_Manager): Pack Project |
| [CfgConvert](https://community.bistudio.com/wiki/CfgConvert) | Config binarisation | [Arma Reforger:Resource Manager](https://community.bistudio.com/wiki/Arma_Reforger:Resource_Manager): Pack Project |
| [Sound Tools](https://community.bistudio.com/wiki/Sound_Tools) | Audio file conversion | [Arma Reforger:Resource Manager](https://community.bistudio.com/wiki/Arma_Reforger:Resource_Manager): Import (audio) |
| [ImageToPAA](https://community.bistudio.com/wiki/ImageToPAA) | Image file conversion | [Arma Reforger:Resource Manager](https://community.bistudio.com/wiki/Arma_Reforger:Resource_Manager): Import (image) |
| [FontToTga](https://community.bistudio.com/wiki/FontToTga) | Font conversion | [Arma Reforger:Resource Manager](https://community.bistudio.com/wiki/Arma_Reforger:Resource_Manager): Font Viewport |
| [FBX to RTM](https://community.bistudio.com/wiki/FBX_to_RTM) | Animation conversion | [Arma Reforger:Animation Editor](https://community.bistudio.com/wiki/Arma_Reforger:Animation_Editor) |
| [Object Builder](https://community.bistudio.com/wiki/Object_Builder) | 3D modelisation | External Editor + [Arma Reforger:Resource Manager](https://community.bistudio.com/wiki/Arma_Reforger:Resource_Manager) / [Arma Reforger:World Editor](https://community.bistudio.com/wiki/Arma_Reforger:World_Editor) |
| [Terrain Builder](https://community.bistudio.com/wiki/Terrain_Builder) | Terrain generation | [Arma Reforger:World Editor](https://community.bistudio.com/wiki/Arma_Reforger:World_Editor) |
| [Game Updater](https://community.bistudio.com/wiki/Game_Updater) | devBranch updater | n/a |
| [FSM Editor](https://community.bistudio.com/wiki/FSM_Editor) | AI editor | [Arma Reforger:Behavior Editor](https://community.bistudio.com/wiki/Arma_Reforger:Behavior_Editor) |
| [Publisher](https://community.bistudio.com/wiki/Publisher) | Content publisher | [Arma Reforger:Resource Manager](https://community.bistudio.com/wiki/Arma_Reforger:Resource_Manager): Publish Project |
| [Terrain Processor](https://community.bistudio.com/wiki/Terrain_Processor) | Terrain object population | [Arma Reforger:World Editor](https://community.bistudio.com/wiki/Arma_Reforger:World_Editor) |
| [TexView 2](https://community.bistudio.com/wiki/TexView_2) | Texture importer/viewer | [Arma Reforger:Resource Manager](https://community.bistudio.com/wiki/Arma_Reforger:Resource_Manager): Import (image), Image Viewport |
