The Signal Editor is a sub-component of the [Arma Reforger:Audio Editor](https://community.bistudio.com/wiki/Arma_Reforger:Audio_Editor), where the user can edit the internal configurations of [Signal nodes](https://community.bistudio.com/wiki/Arma_Reforger:Audio_Editor:_Signal_Editor:_Nodes).
Using the available node types in the Signal Editor, the user can define the input/output behaviour of the Signal resource opened in the editor, transforming one or more inputs into one or more outputs.

## User Interface

The Signal Editor UI is identical to that of Audio Editor, save for the types of nodes available in the Nodes palette.

**Note:** See [Arma Reforger:Audio Editor: Signal Editor: Nodes](https://community.bistudio.com/wiki/Arma_Reforger:Audio_Editor:_Signal_Editor:_Nodes).
