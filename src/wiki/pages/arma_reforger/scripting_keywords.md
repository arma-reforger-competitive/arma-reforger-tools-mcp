## Class Keywords

| Keyword | Description |
| --- | --- |
| ****class**** | Declares a class<br>`class ExampleClass`<br>`{`<br>`}` |
| ****modded**** | See [Arma Reforger:Object Oriented Programming Advanced Usage#Modding](https://community.bistudio.com/wiki/Arma_Reforger:Object_Oriented_Programming_Advanced_Usage#Modding).<br>`class ExampleClass`<br>`{`<br>`}`<br>`modded class ExampleClass // inherits and "takes the place" of the original ExampleClass`<br>`{`<br>`}` |
| ****sealed**** | A class marked with the **sealed** keyword cannot be inherited from<br>`sealed class Infertile`<br>`{`<br>`}`<br>`class Child : Infertile // compilation error - a class cannot inherit from a sealed class`<br>`{`<br>`}` |
| ****extends**** | states that the declared class inherits from another<br>`class ChildClass extends ParentClass`<br>`{`<br>`}`<br>`// alias`<br>`class ChildClass : ParentClass`<br>`{`<br>`}` |
| ****typedef**** | Declares an alias for a type<br>`typedef string Text;`<br>`class ExampleClass`<br>`{`<br>`Text m_sMyText = "This is my text, that is a string";`<br>`}` |

## Method Keywords

| Keyword | Description |
| --- | --- |
| ****proto**** | Disclose an engine-side method to script (Engine side). |
| ****external**** | Compiler hint to link API methods - only applies to `proto` methods (Engine side). |
| ****native**** | Native call convention of internal method (Engine side). |
| ****volatile**** | Internal method that may call back to script (hint for compiler that context need to be saved on stack). |
| ****private**** | Modifier for class method. The method can be called only from inside of the same class' methods. A modded class will still be able to use it (but not its children).<br>`class ExampleClass`<br>`{`<br>`private void HelloWorld()`<br>`{`<br>`Print("Hello there");`<br>`}`<br>`void PublicHelloWorld()`<br>`{`<br>`HelloWorld(); // works from within the object`<br>`}`<br>`}`<br>`ExampleClass classInstance = new ExampleClass();`<br>`classInstance.PublicHelloWorld();	// works - calls PublicHelloWorld() that calls HelloWorld()`<br>`classInstance.HelloWorld();			// compilation error - HelloWorld() is private and cannot be accessed` |
| ****protected**** | Modifier for class method. The method can be called only from inside of class' methods or methods of its extended (children) classes, or a modded class.<br>`class ParentClass`<br>`{`<br>`protected void HelloWorld()`<br>`{`<br>`Print("Hello there");`<br>`}`<br>`}`<br>`class ChildClass : ParentClass`<br>`{`<br>`void PublicHelloWorld()`<br>`{`<br>`HelloWorld(); // works from within the object`<br>`}`<br>`}`<br>`ChildClass classInstance = new ChildClass();`<br>`classInstance.PublicHelloWorld();	// works - calls PublicHelloWorld() that calls HelloWorld()`<br>`classInstance.HelloWorld();			// compilation error - HelloWorld() is protected and cannot be accessed`<br>`ParentClass classInstance = new ParentClass();`<br>`classInstance.HelloWorld();			// compilation error - HelloWorld() is protected and cannot be accessed` |
| ****static**** | Modifier for class method. The method can be called without object pointer, just by ClassName.methodName(). Only static values/methods can be accessed from a static method.<br>`class ExampleClass`<br>`{`<br>`static void HelloWorld()`<br>`{`<br>`Print("Hello there");`<br>`}`<br>`}`<br>`ExampleClass.HelloWorld();	// works`<br>`ExampleClass classInstance = new ExampleClass();`<br>`classInstance.HelloWorld();	// works` |
| ****event**** | Hint for tools that the method should be exposed as Entity script event. |
| ****override**** | Modifier for class method indicating overriding of base class method. Compiler checks if is method present in base class and if method signature matches.<br>`class ParentClass`<br>`{`<br>`void HelloWorld()`<br>`{`<br>`Print("Hello world");`<br>`}`<br>`}`<br>`class ChildClass : ParentClass`<br>`{`<br>`override void HelloWorld()`<br>`{`<br>`Print("Hello there");`<br>`}`<br>`}`<br>`ParentClass parentClassInstance = new ParentClass();`<br>`parentClassInstance.HelloWorld();	// prints "Hello world"`<br>`ChildClass childClassInstance = new ChildClass();`<br>`childClassInstance.HelloWorld();	// prints "Hello there"`<br>**Warning:** Please note that an overridden `static` method uses the object's currently-known class:<br>`class ParentClass`<br>`{`<br>`static int GetAge()`<br>`{`<br>`return 50;`<br>`}`<br>`}`<br>`class ChildClass : ParentClass`<br>`{`<br>`override static int GetAge()`<br>`{`<br>`return 10;`<br>`}`<br>`}`<br>`ChildClass child = new ChildClass();`<br>`ParentClass childAsParent = child;`<br>`Print(childAsParent.GetAge());	// returns 50`<br>`Print(child.GetAge());			// returns 10` |
| ****sealed**** | Modifier for class method. The method cannot be overridden in derived classes.<br>`class ParentClass`<br>`{`<br>`sealed void HelloWorld()`<br>`{`<br>`Print("Hello there");`<br>`}`<br>`}`<br>`class ChildClass : ParentClass`<br>`{`<br>`override void HelloWorld() // compilation error - cannot override a sealed method`<br>`{`<br>`Print("Hello world");`<br>`}`<br>`}` |

## Value Keywords

| Keyword | Description |
| --- | --- |
| ****owned**** | Modifier for returning internal methods. Tells the script VM that the returning variable (string or array) must not be released. |
| ****out**** | Modifier for method parameters. It means that the argument may be changed by the method call.<br>`void Method(out array<string> parameter)`<br>`{`<br>`parameter = {};`<br>`parameter.Insert("Hello");`<br>`parameter.Insert("there");`<br>`}`<br>`// ...`<br>`array<string> myArray = null;`<br>`Method(myArray); // myArray is now { "Hello", "there" }` |
| ****inout**** | Modifier for method parameters. It means that the argument will be used and may be changed by the method call.<br>`class ExampleClass`<br>`{`<br>`private ref array<string> m_aOldParameter;`<br>`void Method(inout array<string> parameter)`<br>`{`<br>`m_aOldParameter = parameter;`<br>`parameter = {};`<br>`parameter.Insert("Hello");`<br>`parameter.Insert("there");`<br>`}`<br>`}`<br>`ExampleClass classInstance = new ExampleClass();`<br>`array<string> myArray = null;`<br>`classInstance.Method(myArray); // myArray is now { "Hello", "there" } and classInstance.m_aOldParameter is referencing myArray's old value` |
| ****const**** | Declares a constant, that is a value that cannot be modified later.<br>`const string MY_TEXT = "Hello there";`<br>`void Method1()`<br>`{`<br>`Print(MY_TEXT); // will print "Hello there"`<br>`MY_TEXT = "General Kenobi"; // compilation error - a constant is set in stone and cannot be modified`<br>`}`<br>`void Method2()`<br>`{`<br>`const string myUnmodifiableString = "Hello there"; // constant valid for method's scope`<br>`Print(myUnmodifiableString);`<br>`myUnmodifiableString = "General Kenobi"; // compilation error`<br>`}` |
| ****reference**** | Hint for tools (Material editor) that the value may be used as parameter in material. |
| ****notnull**** | Modifier for method parameter of class pointer type. It means that the method expect the parameter to never be **null**; if a null value is provided, a VM Exception is raised and the method is not called.<br>`void Method(notnull IEntity entity) // no need to check for "if (!entity)" inside the method`<br>`{`<br>`entity.DoSomething(); // the argument can be accessed safely`<br>`}`<br>`if (myEntity) // it is still needed to check for null before calling the method`<br>`{`<br>`Method(myEntity);`<br>`}` |
| ****private**** | Value can only be accessed from the class/instance methods. Mutually exclusive with "protected".<br>`class ExampleClass`<br>`{`<br>`private bool m_bIsActive;`<br>`void SetActive(bool value)`<br>`{`<br>`m_bIsActive = value;`<br>`}`<br>`}`<br>`ExampleClass classInstance = new ExampleClass();`<br>`Print(classInstance.m_bIsActive); // compilation error - m_bIsActive is private and cannot be accessed` |
| ****protected**** | Value can only be accessed from the class/instance methods or its children. Mutually exclusive with "private".<br>`class ParentClass`<br>`{`<br>`protected bool m_bProtected;`<br>`private bool m_bPrivate;`<br>`void SetPrivate(bool value)`<br>`{`<br>`m_bPrivate = value;`<br>`}`<br>`}`<br>`class ChildClass : ParentClass`<br>`{`<br>`void SetProtected(bool value)`<br>`{`<br>`m_bProtected = value; // works - m_bProtected declaration reaches ChildClass`<br>`}`<br>`}`<br>`ChildClass childClassInstance = new ChildClass();`<br>`Print(childClassInstance.m_bProtected); // compilation error - m_bProtected is protected and cannot be accessed` |
| ****static**** | Value belongs to the class and not an instance of it. If public, it can be accessed without object pointer, just by `ClassName.variable`<br>`class ExampleClass`<br>`{`<br>`static bool bStaticValue;`<br>`private static bool m_bPrivate; // it is good practice to make it protected/private and have getters/setters instead`<br>`}`<br>`Print(ExampleClass.bStaticValue);	// works`<br>`ExampleClass.bStaticValue = true;	// works`<br>`ExampleClass classInstance = new ExampleClass();`<br>`Print(classInstance.bStaticValue);	// works`<br>`classInstance.bStaticValue = true;	// works`<br>**Warning:** Due to the nature of per-scenario mod loading/unloading, `static` properties **are reset game-wide** on modded scenario start/leave due to game and scripts' entire reload. |
| ****autoptr**** | Modifier for class/pointer values. Pointed object will be automatically destroyed upon end of variable lifetime (end of scope, or deletion of class, that contain it).<br>**Note:** This keyword is useless in scripting as all classes inherit `Managed`, therefore are managed by [ARC](https://community.bistudio.com/wiki/Arma_Reforger:Scripting:_Automatic_Reference_Counting). |
| ****ref**** | Strong reference. See [Automatic Reference Counting](https://community.bistudio.com/wiki/Arma_Reforger:Scripting:_Automatic_Reference_Counting) for more information. |

## Code Keywords

| Keyword | Description |
| --- | --- |
| ****auto**** | Guess the type of the variable. Its usage is **not** recommended (see [Best Practices](https://community.bistudio.com/wiki/Arma_Reforger:Scripting:_Best_Practices))!<br>`auto myVar = 5; // understood as int myVar = 5`<br>`// but it may have been meant as:`<br>`float myVar = 5;` |
| ****new**** | Creates an instance of the provided class.<br>`class ExampleClass`<br>`{`<br>`}`<br>`ExampleClass classInstance = new ExampleClass();`<br>`class ExampleClass`<br>`{`<br>`void ExampleClass(int myValue) // a method named from the class is the constructor`<br>`{`<br>`Print(myValue);`<br>`}`<br>`}`<br>`ExampleClass classInstance = new ExampleClass(5); // needs Constructor-defined arguments` |
| ****delete**** | Deletes an object and sets all its references to `null`.<br>**Important:** It is not possible to delete an object if there is an external reference to it, like an array.<br>`class ExampleClass`<br>`{`<br>`void Method()`<br>`{`<br>`ReferencedClass obj;`<br>`if (!obj)`<br>`Print("obj is null");`<br>`obj = new ReferencedClass();`<br>`if (obj)`<br>`Print("obj is not null");`<br>`delete obj;`<br>`if (!obj)`<br>`Print("obj is null");`<br>`// everything was fine`<br>`obj = new ReferencedClass();`<br>`if (obj)`<br>`Print("obj is not null");`<br>`array<ref ReferencedClass> list = {};`<br>`list.Insert(obj);`<br>`delete obj; // throws a VM Exception`<br>`}`<br>`}` |
| ****thread**** | Creates a script thread from a method.<br>**Important:**<br>- `thread` is to be used in Workbench plugins. In game, use the `GetGame().GetCallQueue().CallLater()` method.<br>- A script thread is not a real thread and member variables are therefore "thread-safe".<br>`class ExampleClass`<br>`{`<br>`// calling this method will print`<br>`// "MainMethod start"`<br>`// "ThreadMethod start",`<br>`// "MainMethod end"`<br>`// then 500ms later, "ThreadMethod end"`<br>`void MainMethod()`<br>`{`<br>`Print("MainMethod start");`<br>`thread ThreadMethod();`<br>`Print("MainMethod end");`<br>`}`<br>`protected void ThreadMethod()`<br>`{`<br>`Print("ThreadMethod start");`<br>`Sleep(500);`<br>`Print("ThreadMethod end");`<br>`}`<br>`}`<br>**Thread methods are only possible within a threaded method:**<br>- `Sleep` takes an integer and waits for the provided amount of milliseconds<br>- `Wait` takes a bool condition and holds until the provided condition is true |
| ****null**** | A null value. |
| ****this**** | Refers to the method's object itself.<br>`class ExampleClass`<br>`{`<br>`void MethodA()`<br>`{`<br>`this.MethodB();`<br>`}`<br>`void MethodB()`<br>`{`<br>`Print("It works");`<br>`}`<br>`}`<br>Since Arma Reforger 1.1.0, `this` is supported in static methods and behaves like the current type.<br>`class Gen1`<br>`{`<br>`static void DoSmth() { Print("A"); }`<br>`}`<br>`class Gen2 : Gen1`<br>`{`<br>`static override void DoSmth(Widget utility)`<br>`{`<br>`Print("B");`<br>`Print(this); // > Gen2`<br>`}`<br>`}` |
| ****super**** | Refers to the **parent** class for the requested variable/method.<br>`class Gen1`<br>`{`<br>`void Method()`<br>`{`<br>`Print("Gen1 method");`<br>`}`<br>`}`<br>`class Gen2 : Gen1`<br>`{`<br>`override void Method()`<br>`{`<br>`Print("Gen2 method");`<br>`}`<br>`}`<br>`class Gen3 : Gen2`<br>`{`<br>`override void Method()`<br>`{`<br>`super.Method(); // prints "Gen2 method"`<br>`}`<br>`}`<br>Since Arma Reforger 1.1.0, `super` is supported in static methods and behaves like a type.<br>`class Gen1`<br>`{`<br>`static int a = 33;`<br>`int b = 42;`<br>`static void ShowMessage() { Print("A"); }`<br>`}`<br>`class Gen2 : Gen1`<br>`{`<br>`static override void ShowMessage(Widget utility)`<br>`{`<br>`Print("B");`<br>`Print(super);			// > Gen1`<br>`Print(super.a);			// > a = 33`<br>`// Print(super.b); <- error - not a static property`<br>`super.ShowMessage();	// > "A"`<br>`}`<br>`}` |
| ****vanilla**<br>Arma Reforger 1.1.0** | Refers to the **unmodded** version of the modded variable/method.<br>`class ClassA`<br>`{`<br>`static void Hello()`<br>`{`<br>`Print("vanilla");`<br>`}`<br>`}`<br>`// mod 1 content`<br>`modded class ClassA`<br>`{`<br>`override static void Hello()`<br>`{`<br>`Print("modded 1");`<br>`}`<br>`}`<br>`// mod 2 content`<br>`modded class ClassA`<br>`{`<br>`override static void Hello()`<br>`{`<br>`super.Hello();`<br>`vanilla.Hello();`<br>`Print("modded 2");`<br>`}`<br>`}`<br>`void Test()`<br>`{`<br>`ClassA o = new ClassA();`<br>`o.Hello(); // prints modded 1, vanilla, modded 2`<br>`}` |
| **debug** | Triggers a breakpoint in [Arma Reforger:Script Editor](https://community.bistudio.com/wiki/Arma_Reforger:Script_Editor).<br>**Note:** This keyword is currently not highlighted as such in Script Editor.<br>`class MyClass`<br>`{`<br>`[Attribute(defvalue: "0", desc: "Use breakpoints in Workbench")]`<br>`protected bool m_bUseBreakpoints;`<br>`static void Hello()`<br>`{`<br>`Print("This is debugging");`<br>`#ifdef WORKBENCH`<br>`if (m_bUseBreakpoints)`<br>`debug;`<br>`#endif // WORKBENCH`<br>`}`<br>`}` |

## Code Flow Keywords

| Keyword | Description |
| --- | --- |
| ****if**** | verifies a boolean condition. If the condition is true then the code is executed.<br>`void Method(int value = 0)`<br>`{`<br>`if (value > 50)`<br>`Print("value is > 50");`<br>`}` |
| ****else**** | optional, declares code to be executed if the if condition is not met<br>`void Method(int value = 0)`<br>`{`<br>`if (value > 50)`<br>`Print("value is > 50");`<br>`else`<br>`Print("value is <= 50");`<br>`}` |
| ****for**** | processes code while the provided condition is met. The syntax is:<br>`for (initialisation; loopCondition; completionCode)`<br>`{`<br>`// code here`<br>`}`<br>`void MethodA(notnull array<string> words)`<br>`{`<br>`// for (int i = 0; i < words.Count(); i++) // this if for example's sake; use '''foreach''' instead`<br>`for (int i, count = words.Count(); i < count; ++i) // optimised`<br>`{`<br>`Print(words[i]);`<br>`}`<br>`}`<br>`void MethodB(notnull array<string> words)`<br>`{`<br>`int i; // auto-initialised to zero`<br>`int count = words.Count();`<br>`for (; i < count; i++) // initialisation is optional`<br>`{`<br>`Print(words[i]);`<br>`}`<br>`}`<br>`void MethodC(notnull array<string> words)`<br>`{`<br>`for (int i, count = words.Count(); i < count;) // so is completionCode`<br>`{`<br>`Print(words[i]);`<br>`i++; // do not forget it!`<br>`}`<br>`}` |
| ****foreach**** | processes code for each element of an iterable object (e.g an array). Iteration separator is`:`.<br>`// array example`<br>`void Method(notnull array<string> words)`<br>`{`<br>`foreach (string word : words)`<br>`{`<br>`Print(word);`<br>`}`<br>`foreach (int index, string word : words)`<br>`{`<br>`PrintFormat("word #%1 is %2", index, word);`<br>`}`<br>`}`<br>`// map example`<br>`void Method(notnull map<string, int> data)`<br>`{`<br>`foreach (string key, int value : data)`<br>`{`<br>`PrintFormat("Key %1's value is %2", key, value);`<br>`}`<br>`}` |
| ****while**** | processes code while condition is met. Beware, as it can lock the program on wrong conditions!<br>`void Method(array<string> words)`<br>`{`<br>`int i = 0;`<br>`while (i < words.Count())`<br>`{`<br>`Print(words[i]);`<br>`i++; // do not forget it!`<br>`}`<br>`}` |
| ****switch**** | switches the code to execute depending on the condition<br>`void Method(string word)`<br>`{`<br>`switch (word)`<br>`{`<br>`case "Hello":`<br>`Print("it's Hello");`<br>`break;`<br>`case "there":`<br>`Print("it's there");`<br>`break;`<br>`default:`<br>`Print("it's not interesting.");`<br>`break;`<br>`}`<br>`}` |
| **continue** | Used to skip to the next iteration in `for`, `foreach`, `while` loops<br>`class ExampleClass`<br>`{`<br>`// this method will print 0, 1, 2, 4`<br>`void Skip3()`<br>`{`<br>`for (int i; i < 5; i++)`<br>`{`<br>`if (i == 3)`<br>`continue;`<br>`Print(i.ToString());`<br>`}`<br>`}`<br>`void MethodB()`<br>`{`<br>`foreach (IEntity entity : m_aEntities)`<br>`{`<br>`if (!entity)`<br>`continue;`<br>`Print(entity);`<br>`}`<br>`}`<br>`}` |
| ****return**** | Exits the method immediately with the provided value if any.<br>`class ExampleClass`<br>`{`<br>`void PrintHelloThere(bool print)`<br>`{`<br>`if (!print)`<br>`return; // ends here if print is false`<br>`Print("Hello there");`<br>`}`<br>`float GetDistanceNotZero(vector v1, vector v2)`<br>`{`<br>`if (v1 == v2)`<br>`return -1;`<br>`return vector.Distance(v1, v2);`<br>`}`<br>`}` |
