**Note:**

| red		means a heavy impact on performance<br>orange	means an average impact<br>green		means little to no performance impact. |  |
| --- | --- |

| Category | Setting | CPU | GPU | RAM | VRAM | Additional Details |
| --- | --- | --- | --- | --- | --- | --- |
| **Presets** | Quality Presets | red | red | red | red | Choose from one of four quality presets. Preset *Custom* is automatically set once a setting was adjusted manually. |
| **General** | Window mode | green | green |  |  | Defines how the window is displayed. Also influences the Render Scale / Resolution setting. |
| **General** | Render scale / Resolution | green | red |  |  | Define the resolution at which the game scene will be rendered. A reduced resolution will drastically improve performance and a very high loss of image quality. It is recommended to use the default monitor resolution (100%). |
| **General** | FidelityFX Super Resolution 1.0 | green | orange |  |  | Enables [AMD FidelityFX™ Super Resolution](https://www.amd.com/en/technologies/fidelityfx-super-resolution) |
| **General** | V-Sync | green | green |  |  | Vertical synchronisation prevents image tearing, to the potential cost of input lag. |
| **General** | FPS limit | green | green |  |  | Limit your FPS to reduce stuttering and power consumption due to unnecessary high frame rates. |
| **General** | Draw distance | red | green |  |  | Sets the overall terrain draw distance. |
| **General** | Nearby depth of field | green | red |  |  | Enable or disable nearby Depth of Field (especially visible when aiming down sights). |
| **Post-processing** | Post-process anti aliasing | orange | red |  |  | Choose between None, FXAA low, FXAA high, SMAA low, SMAA high. |
| **Post-processing** | Depth of field quality | green | green |  |  | Choose between None, Simple or Bokeh (more accurate but more expensive). |
| **Post-processing** | Ambient occlusion (HBAO) | green | orange |  |  | Ambient occlusion is a rendering method that provides an approximation of how bright light should be at different parts of a visible surface. |
| **Post-processing** | Screen space reflections | green | red |  |  | Defines how many reflections are shown in the scene and their quality. |
| **Post-processing** | Contact shadows | green | orange |  |  | Enables [space directional occlusion SSDO](https://en.wikipedia.org/wiki/Screen)'s contact shadows. |
| **Quality** | Hardware anti-aliasing | green | red |  |  | See https://en.wikipedia.org/wiki/Multisample_anti-aliasing. |
| **Quality** | Foliage smoothing | orange | orange |  |  | Defines if and what foliage is smoothed. Only available if **Hardware anti-aliasing** is at least set to *Low*. |
| **Quality** | Model geometric detail | green | orange |  |  | Sets the overall quality of model geometry. |
| **Quality** | Object draw distance | red | green |  |  | Sets the objects' maximum draw distance from the camera, relative to Terrain's draw distance. |
| **Quality** | Terrain surface detail | green | orange |  |  | Sets the terrain's shader quality. |
| **Quality** | Texture detail | red | orange |  | red | Sets the overall texture quality. |
| **Quality** | Texture filtering | red | green |  |  | Define https://en.wikipedia.org/wiki/Texture_filtering quality. |
| **Quality** | Grass quality | green | red |  |  | Sets the overall grass quality. |
| **Quality** | Grass draw distance | red | red |  |  | Sets the rendering distance of grass and other 3D clutters (small rocks, etc). |
| **Quality** | Shadow quality | green | orange |  |  | Sets the overall shadow quality. |
| **Quality** | Distant shadows | green | orange |  |  | Rendering distance of shadows. |
| **Quality** | Render target format | red | green |  | red | Choose between 32 or 64-bit colour render. |
| **Quality** | Environment quality | green | orange |  |  | Affects volumetric clouds quality (number of samples, temporal filter settings, noise resolution etc), sky rendering quality (texture resolution, fog, cascade shadow), rain quality. |
