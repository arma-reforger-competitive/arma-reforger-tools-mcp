# Rust for the MCP server

The MCP server is written in Rust with the official MCP SDK `rmcp`. The strict compiler catches more mistakes in code that AI writes. The server is one program, so users do not need Node. Rust is fast for search over the Knowledge base and for reading .pak files. The owner also wants to learn Rust. We switched when only one tool (`wiki_read`) existed, so the switch was cheap.

## Considered options

- **Stay with TypeScript and Node 24.** Node is fast enough for one local user, and a Port could copy the old code. We rejected it for the reasons above. The cost: each Port now translates the old TypeScript instead of copying it.

## Consequences

- Users build the server with `cargo build --release`. When the first user who is not the owner installs the plugin, CI builds the server for Linux and Windows and publishes it on GitHub Releases.
